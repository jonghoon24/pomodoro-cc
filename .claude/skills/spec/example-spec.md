# 포모도로 1차 버전 스펙

## 목표

25분 집중과 5분 휴식을 번갈아 하도록 돕는 포모도로 타이머 웹앱을 만든다. 이번 집중에 할 일을 적어 두고, 다른 탭에서 작업하는 중에도 집중과 휴식이 끝나는 때를 놓치지 않게 한다.

- React 웹앱이고 서버 없이 브라우저에서만 동작한다.
- 화면 문구는 모두 한국어로 쓴다.

## 이번에 만드는 기능

### 1. 타이머 상태

| 상태 | 표시 시간 | 버튼 |
|---|---|---|
| 집중 대기 | 25:00 | 시작 |
| 집중 진행 | 줄어드는 남은 시간 | 일시정지, 초기화 |
| 집중 일시정지 | 멈춘 남은 시간 | 계속, 초기화 |
| 휴식 진행 | 줄어드는 남은 시간 | 일시정지, 초기화 |
| 휴식 일시정지 | 멈춘 남은 시간 | 계속, 초기화 |

- 남은 시간은 `MM:SS` 형식으로 보여 준다.
- 지금이 집중인지 휴식인지 화면에서 바로 알 수 있어야 한다.
- 앱을 처음 열면 집중 대기 상태다.

### 2. 상태 전환

- **시작**: 집중 대기 → 집중 진행. 25분 카운트다운을 시작한다.
- **일시정지 / 계속**: 남은 시간을 그대로 두고 멈추거나 다시 진행한다. 집중과 휴식 모두 같다.
- **집중 종료**: 집중이 0:00이 되면 알림 소리를 내고, 사용자가 누르지 않아도 5분 휴식이 바로 시작된다.
- **휴식 종료**: 휴식이 0:00이 되면 알림 소리를 내고 집중 대기(25:00)로 돌아간다. 다음 집중은 자동으로 시작하지 않는다. 이때 화면은 처음 앱을 열었을 때의 대기 화면과 같다.
- **초기화**
  - 집중 중(진행이나 일시정지)에 누르면 집중 대기(25:00)로 돌아간다.
  - 휴식 중(진행이나 일시정지)에 누르면 휴식을 끝내고 집중 대기(25:00)로 돌아간다. 이것이 휴식을 건너뛰는 방법이다.
  - 확인 창 없이 바로 적용한다.

### 3. 알림 소리

- 집중이 끝날 때와 휴식이 끝날 때 2~3초 길이의 소리를 한 번 낸다. 두 경우 모두 같은 소리를 쓴다.
- 소리는 앱에 들어 있어서 외부 네트워크 없이 재생된다.
- 사용자가 다른 탭을 보고 있어도 종료 시점에 맞춰 소리가 나야 한다.

### 4. 시간 계산 (백그라운드)

- 남은 시간은 실제로 흐른 시각을 기준으로 계산한다. 화면 갱신 횟수를 세는 방식으로 계산하지 않는다.
- 다른 탭에 있다가 돌아오면, 그동안 흐른 시간을 반영한 상태를 바로 보여 준다.
  - 예: 집중이 10분 남았을 때 다른 탭으로 갔다가 12분 뒤에 돌아오면 휴식 3분 남음 상태다.
  - 예: 같은 상황에서 40분 뒤에 돌아오면 집중도 휴식도 이미 끝났으므로 집중 대기(25:00) 상태다.

### 5. 할 일 메모

- 여러 줄을 쓸 수 있는 자유 형식 메모 한 칸이다. 체크 기능은 없다.
- 타이머가 어떤 상태든 언제나 수정할 수 있다.
- 비어 있어도 시작할 수 있다.
- 집중이 끝나거나 초기화해도 메모 내용은 그대로 남는다. 바꾸고 싶으면 사용자가 직접 고친다.
- 새로고침하거나 탭을 닫으면 메모는 사라진다. 따로 저장하지 않는다.

### 6. 탭 제목

- 집중이나 휴식이 진행 중이거나 일시정지된 동안에는 탭 제목에 남은 시간과 모드를 보여 준다.
  - 예: `18:42 · 집중`, `03:10 · 휴식`
  - 일시정지 중에는 일시정지 상태임을 함께 표시한다. 예: `⏸ 18:42 · 집중`
- 집중 대기 상태에서는 앱 이름을 보여 준다.

### 7. 새로고침

- 새로고침하거나 탭을 다시 열면 항상 집중 대기(25:00)에서 시작한다. 타이머 상태도 메모도 복원하지 않는다.

## 안 하는 것

- 집중과 휴식 시간 설정
- 지난 기록 보기, 완료한 포모도로 횟수 세기
- 브라우저 알림(Notification API)
- 4회마다 오는 긴 휴식
- 휴식이 끝난 뒤 다음 집중 자동 시작
- 새로고침이나 탭 닫기 후 타이머와 메모 복원, 닫기 전 경고 창
- 초기화 확인 창, 별도의 '휴식 건너뛰기' 버튼
- 알림 소리 선택, 볼륨 조절, 반복 재생
- 휴식이 끝난 직후 대기 화면에 따로 안내 문구 띄우기
- 할 일 목록(여러 항목, 완료 체크)
- 서버, 로그인, 기기 간 동기화

## 완료 조건

- AC-1: 앱을 처음 열면 집중 대기 상태로 `25:00`과 시작 버튼이 보이고, 탭 제목은 앱 이름이다.
- AC-2: 시작을 누르면 남은 시간이 1초씩 줄어들고, 탭 제목에 `24:59 · 집중`처럼 남은 시간과 모드가 보인다.
- AC-3: 집중이나 휴식 중에 일시정지를 누르면 시간이 멈추고 탭 제목 앞에 `⏸`가 붙는다. 계속을 누르면 멈춘 시간부터 다시 줄어든다.
- AC-4: 집중이나 휴식 중에 초기화를 누르면 확인 창 없이 바로 집중 대기 `25:00`으로 돌아간다.
- AC-5: 집중이 `00:00`이 되면 알림 소리가 한 번 나고, 아무것도 누르지 않아도 `05:00` 휴식이 시작된다.
- AC-6: 휴식이 `00:00`이 되면 알림 소리가 한 번 나고 집중 대기 `25:00`으로 돌아가며, 다음 집중은 시작되지 않는다.
- AC-7: 집중 중인지 휴식 중인지 화면에서 바로 구분된다.
- AC-8: 집중이 10분 남았을 때 다른 탭으로 옮겨 12분 뒤에 돌아오면 휴식이 3분 남아 있다.
- AC-9: 집중이 10분 남았을 때 다른 탭으로 옮겨 40분 뒤에 돌아오면 집중 대기 `25:00`이다.
- AC-10: 다른 탭을 보고 있어도 집중이 끝나는 시점에 맞춰 알림 소리가 난다.
- AC-11: 메모에 여러 줄을 입력할 수 있고, 대기, 진행, 일시정지, 휴식 중 언제든 고칠 수 있다. 메모가 비어 있어도 시작할 수 있다.
- AC-12: 메모를 적고 집중과 휴식을 거쳐 대기로 돌아오거나 초기화해도 메모가 그대로 남는다.
- AC-13: 진행 중에 새로고침하면 메모가 비고 타이머는 집중 대기 `25:00`이다.
- AC-14: 네트워크를 끈 상태에서도 알림 소리가 재생된다.
